# The HyperFrames build

How the project is laid out, the contract in short, and what to do with each `check` finding.
`/hyperframes-core` is the full contract. Read it before writing scene HTML the first time.

## Project layout

```
<project>/
  index.html                 GENERATED by scaffold.py: root "main", one host clip per scene,
                             transitions on the root timeline, every <audio>. Never hand-edit.
  storyboard.json            YOU: size, fps, palette, fonts, scenes (duration, enter), music, cues
  storyboard.timing.json     GENERATED: computed scene/cue times (contact sheet, audio check)
  PLAN.md                    YOU: brief, scene decisions, validation numbers
  compositions/<id>.html     YOU: one <template> sub-composition per scene, own paused timeline
  assets/fonts/              woff2 + licenses (bundled ones are copied in automatically)
  assets/music/ sfx/ vo/ images/ video/    media; paths are project-relative
  package.json               pins the CLI version: use npx -y hyperframes@<pin>
```

Lifecycle: `init` → delete the starter `index.html` → write `storyboard.json` → `scaffold.py`
(writes `index.html`, skeletons for new scenes) → author scenes → edit `storyboard.json` and
re-run as often as needed. A re-run never overwrites scene files (only `--force-scenes` does).

## The contract in short (what scaffold.py and the skeleton already obey)

- **Root**: `<div id="root" data-composition-id="main" data-width data-height data-duration data-fps>`
  sits directly in `<body>` with no `<template>`. GSAP loads once in the root's `<head>`.
- **Hosts**: `<div id="<id>" class="clip" data-composition-id="<id>" data-composition-src="compositions/<id>.html" data-start data-duration data-track-index data-width data-height>`.
  Host id = template root `data-composition-id` = `window.__timelines` key. A mismatch silently
  renders frozen frames.
- **Scene files**: the root inside `<template>`, with `<style>` and `<script>` **inside** the
  template (the assembler drops a templated file's own `<head>` styles). The script is an IIFE
  that builds one `gsap.timeline({ paused: true })` and registers it last.
- **Root timeline**: only transitions (host `xPercent`/`clipPath`/`opacity`/`filter`/`scale`).
  Scene timelines nest automatically. Don't nest them by hand.
- **Visibility belongs to the framework**: never tween `display`, `visibility` or `autoAlpha` on a
  `.clip`. Opacity/transform on a host or an inner node is fine.
- **Determinism**: no `Date.now`, `performance.now`, unseeded `Math.random`, timers, network or
  media `play()`/`pause()`. `repeat: -1` only under a finite root duration. Use `rng(seed)`.
- **Transforms**: never pair a CSS `transform` with a GSAP tween on the same element. Center with
  flex/`inset`, and wrap the element if it needs a static offset.
- **Fonts**: every named `font-family` needs an in-file `@font-face` to a shipped file. The skeleton
  writes them from `storyboard.json → fonts`. In `style="…"` attributes, family names use single quotes.
- **Text**: no `<br>` in body text (use block elements). Transformed elements are block or
  inline-block. `split()` makes inline-block spans.
- **Media**: every `<audio>` has an `id`, never `crossorigin`. A `<video data-start>` must not sit
  inside another timed plain element. Put the timing on one or the other.

## Media in scenes
- Images: `assets/images/…`, referenced as `../assets/images/x.jpg` from a scene file (scene
  files live in `compositions/`).
- Footage: `<video id="s-v" class="clip" src="../assets/video/x.mp4" data-start="0" data-duration="3" data-media-start="12.5" muted></video>`.
  The framework seeks it. Put sound on a separate `<audio>` cue in the storyboard (or leave the
  video's own audio on, deliberately).
- Captions and voiceover transcription: `/media-use` (transcribe), plus the caption guidance in
  `/hyperframes-creative`.
- A website as subject: `npx hyperframes capture <url> --json` gives you screenshots and tokens.

## `check` findings → fixes

| Finding | Cause | Fix |
|---|---|---|
| `first_frame_empty` (craft) | nothing on screen at t=0 | first scene's content visible at 0 (the skeleton does this) |
| `line_unread` | text on screen under its read floor (0.4s for 1–2 words; 0.5 + 0.3/word suggested) or under 0.5 opacity | lengthen the scene/clip (by a whole beat when on a grid), bring the text in earlier, or cut words |
| `text_below_floor` | readable text < 28px at 1080 short side | enlarge it, or `data-layout-ignore` if it's texture (thumbnail labels, background words) |
| contrast `✗ … need 3:1` | accent on a light ground, muted on dark | darken or lighten that scene's palette token (scene-level `palette`), keep the hue |
| `container_overflow` (info) | a camera layer scaled past its container | `data-layout-allow-overflow` on that wrapper (the skeleton's stage has it) |
| `content_overlap` | two scenes' text overlap mid-crossfade/blur, or real overlap | expected mid-dissolve: `data-layout-allow-overlap` on a container inside the scene; otherwise move it |
| `gsap_css_transform_conflict` (lint) | CSS transform + GSAP tween on the same node | move the CSS offset to a wrapper, or put it in the `fromTo` |
| `gsap_animates_clip_element` (lint) | visibility/autoAlpha tween on a `.clip` | tween an inner node |
| `gsap_timeline_set_initial_hide` | `tl.set(…, {opacity:0}, 0)` hiding later content | make it a timed clip, or `fromTo` at its own start |
| `font_family_without_font_face` | a family without a shipped file | add the woff2 to `assets/fonts/` and `storyboard.json → fonts`, then add its `@font-face` to the scene |
| `subcomposition_root_styled_by_class` | scene root styled by class | style it by `#id` |
| `studio_missing_editable_id` | a timed element without an id | give every `.clip` an id |
| `media_missing_id` / `duplicate_audio_track` | hand-placed audio | put audio in `storyboard.json`; the scaffold ids it and packs tracks |
| `multiple_root_compositions` | `music-only.html` left in the project | delete it after the music-only render |
| `audio_none` (info) | silent film | fine if planned silent; otherwise add music/cues |

A lint **error** switches off the layout/contrast/craft audits (`0 samples`), so clear errors
first and don't trust a "clean" report until lint is clean.

## Render notes
- `snapshot` is fast. Use it for every visual check. Render only to judge playback and sound.
- `render --quality draft --workers 2` while iterating; `--quality delivery` once, on approval.
- On Linux without `chrome-headless-shell`, render falls back to screenshot capture with software
  GL. That's slower but correct (an 18s 1080p30 draft takes ~50s on a laptop).
- `npx hyperframes preview --background` opens Studio; edits made there to `index.html` are
  overwritten by the next scaffold run (edits to scene files survive).
