# Faceless Explainer

**What it is:** A narrated, multi-scene piece that explains a concept, topic, or idea using invented visuals (not a specific product capture or a social-platform clip). Covers both punchy educational explainers and slower, atmospheric documentary-style or brand-film pieces — the difference between those two is pacing, not structure (see the pacing note below).

**When to use this category:** The request is "explain this," "make a video about this topic/article/idea," or "tell the story of X," with no specific product UI being captured and no platform dictating pacing. A request for something 60s+ with a clearly slower, atmospheric intent is this category's documentary/brand-film variant, not a separate category.

**Length:** 30–90s typically; the documentary/brand-film variant can run 60s+. 5–10 scenes for the standard pace, fewer and longer for the slow variant.

## How to build it

1. **State the hook before the setup.** The first 3–5 seconds should state the problem, the surprising fact, or the payoff — not a slow wind-up ("Have you ever wondered...") before getting to the point. Value before evidence: tell the viewer what they'll get before building the case for it.
2. **Script first, visuals second.** Write (or get) the narration as a script before planning scenes — the scenes exist to illustrate specific beats of the script, not the other way around. A script written to match visuals that were designed first tends to feel padded.
3. **One visual idea per narration beat**, matching Section 2's one-dominant-idea-per-scene rule — don't let a single sentence of narration span three different visual metaphors, and don't let one visual sit through several unrelated sentences.
4. **Pacing is the main lever between "punchy explainer" and "documentary/brand film":**
   - *Punchy:* shorter holds, more scenes, each one landing one point before moving on. Energetic music tempo (see `../motion-rules.md`).
   - *Slow/documentary:* fewer, longer-held shots; more atmosphere and depth per scene; calmer tempo. This still respects the main skill's ~1s no-dead-air rule — "slow" means deliberate continuing motion held longer, not nothing moving.
5. **Invented visuals still need real grounding.** "Invented" means the visual metaphor is created for the piece (not a literal product capture), not that any numbers or claims inside it can be invented — the fact-sourcing rule in Section 1/2 of the main skill applies fully here, especially for any stat or claim the script makes.
6. **Narration pacing and delivery matter as much as the visuals**: numbers should be written the way they're meant to be spoken (e.g. "nearly half" vs. "47.3%" depending on tone), and sentence length should match the intended pacing from point 4.

**Pitfalls specific to this category:**
- A slow wind-up before the actual point, losing the viewer before the hook lands.
- Visuals that are generic stand-ins (abstract particles, vague gradients) for a concept that could have a specific, considered visual metaphor instead.
- Mismatched pacing — punchy visuals under slow narration, or vice versa.
- Treating the documentary variant as an excuse for more dead air rather than more depth per shot.

**Transitions:** Vary technique across scenes more than other categories can — a multi-minute explainer using the same cut every time starts to feel mechanical. Use match cuts between visually related beats and hard cuts between unrelated ones; save a cross-dissolve for an actual tonal shift (moving from problem to solution, or into the slow/documentary variant's more atmospheric beats). See `../transitions.md`.

**Expected output bar:** A viewer who knew nothing about the topic can explain the core idea back after one watch, and the opening 5 seconds alone would make them want to keep watching.
